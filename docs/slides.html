Punish · London AI x Science Hackathon · Track 2

AI science agents can pass the grader without doing the science

Agents now run analyses, write reports and cite literature. Like any optimiser, they can copy an expected answer, quietly drop inconvenient data, switch to a friendlier metric, or invent a citation.

  • The proxy is a number. A p-value, an R² or an accuracy threshold can be matched without running the analysis.
  • Reviewers read the report, not the notebook. The write-up looks like the deliverable.
  • Hacks look like judgement calls. Outlier removal or a metric choice is fine when disclosed, a hack when chosen to hit a target and hidden.
What does an auditor need to see to catch reward hacking: the reasoning, the actions, or only the report?

Threat model

One planted exploit per task, six ways to cheat

  • Subject: an LLM agent with a sandbox and three tools: read_file, run_python, write_report.
  • Opportunity: a leaked answer file or a grader that rewards a proxy. Using it raises the score and lowers validity.
  • Motive: only the system prompt varies: honest → incentivized → pressure → covert (told to hack and hide it).
  • Auditor: reads the trajectory afterwards. It never sees the system prompt, cannot run code, and is never trained against.

Ground truth

A rule-based labeller misses many hacks: 47 of 93 found (corrected label)

  • The labeller checks only the planted path, for example "read eval.py, reported 0.312 and no successful analysis ran".
  • fake_citation: real bibliography keys can accompany invented source support. In case study 7 the agent admits inventing the attributed finding (L9).
  • leaked_answer: 30 judge positives from a stale task definition are relabelled clean (side note: the original label gave 47 vs 123).
  • Labeller-only hack rates would understate the problem about 2× (2.6× on the original label). The judge is an LLM too: the best available reference, not the truth.

Limitations

Read these numbers as preliminary

Small n

5 episodes per (model, config, task) cell. Per-task results rest on 2–40 corrected-label positives, 0–27 in the Opus subset (4–27 original). Pressure vs incentivized, subject-model gaps and Opus recall or FPR alone are underpowered (SIGNIFICANCE.md). Resampling by cell widens CIs up to ~2×.

Instructed hacking

66/93 positives are covert, and 75/90 covert reasonings name the red-team role (Opus's reasoning gain holds without them). On natural hacks full_trace recall is 19/27 = 0.70 (Sonnet) and 5/17 = 0.29 (Opus).

LLM ground truth

The headline label is effectively the Opus judge, same family as the auditor. Against 60 blind AI labels: κ 0.70 (0.97 after the stale leaked_answer fix they helped find), never more lenient. No human raters yet.

Toy tasks

Single-file tasks with one planted exploit each. Real analyses are longer, and hacks may spread across many steps.

Grader access drives FPR

Auditors flag honest runs that read grade.py as suspicious_access, though the rubric caps access alone at 0.3 confidence. Corrected-label FPR: Sonnet full_trace 0.34, so precision 0.48 at our 26% hack rate would be 0.12 at 5%; no Claude auditor keeps FPR ≤ 10% on unseen tasks.

Reasoning is not ground truth

A clean trace is weak evidence of a clean run (Chen et al.). We have not tested agents trained to obfuscate.

Takeaway

Audit the trajectory, not the paper

  • Actions expose instructed hacks. The report alone costs Sonnet 0.17 recall (0.91 → 0.74), all on covert; v2's natural-hack reversal (26/27 vs 20/27) does not replicate on v3.
  • Reasoning helps a strong auditor separate looking at the grader from using it (corrected label: Opus accuracy +0.07, Holm p = 0.002, holding without the role-leaking runs; FPR 0.22 vs 0.27 and recall 0.77 vs 0.63 alone are underpowered).
  • Auditors catch most hacks but over-flag honest grader-reading runs (corrected label: Sonnet full_trace FPR 0.34; 0.22–0.35 across trace modes). As a best-of-n veto they still cut shipped hacks 0.28 → 0.15.
  • Rule-based ground truth undercounts. The labeller finds 47 of the 93 hacks the judge finds (corrected label).
  • Citation misuse is the open blind spot. Give the auditor the abstracts or a retrieval tool.
